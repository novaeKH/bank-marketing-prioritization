# Приоритизация клиентов для банковского обзвона

Банк не может позвонить всем клиентам, поэтому задача проекта — до звонка оценить вероятность положительного ответа и сформировать приоритетный список.

## Что сделано

- использован UCI Bank Marketing;
- `duration` удалён как признак, недоступный до звонка;
- последние 20% наблюдений оставлены для проверки на будущем периоде;
- Logistic Regression, Decision Tree и Random Forest сравнены на временной кросс-валидации;
- рабочее решение оценивается через Top-K при бюджете 10% клиентов.

## Результат

На финальном периоде:

- AP: 0.530 при baseline 0.308;
- ROC-AUC: 0.745;
- при бюджете 10% выбрано 824 клиента;
- получено 484 положительных ответов против примерно 254 при случайном выборе;
- Precision@10%: 58.7%;
- Recall@10%: 19.1%;
- Lift@10%: 1.91.

Модель сильнее всего опирается на предыдущий контакт, месяц кампании и экономический контекст.

В итоге временное разбиение показало сильное изменение доли положительных ответов между кампаниями. Поэтому я выбрал более простую Logistic Regression, которая оказалась устойчивее сложных моделей на временных фолдах.


Источник данных: UCI Bank Marketing

## Ограничения

Данные относятся к кампаниям 2008–2010 годов. В них нет идентификатора клиента и стоимости звонка. Поэтому проект показывает метод оценки приоритетного списка, но не переносит полученные цифры на современные кампании, не рассчитывает денежную прибыль и не проверяет пересечение одного клиента между периодами.

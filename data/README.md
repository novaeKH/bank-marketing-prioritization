# Bank Marketing data

Источник: [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing).

В проекте используется `bank-additional-full.csv`: полный набор из 41 188
наблюдений и 20 входных признаков, упорядоченный по времени. Описание полей
находится в `raw/bank-additional-names.txt`.

Ожидаемая структура:

```text
data/raw/
├── bank-additional-full.csv
└── bank-additional-names.txt
```

При повторном использовании данных необходимо сохранить ссылку на UCI и
проверить актуальные условия лицензии на странице набора данных.
